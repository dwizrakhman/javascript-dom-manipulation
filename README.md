# JavaScript Event Handling & DOM Manipulation

A collection of hands-on exercises and mini-projects focused on building interactive web pages using JavaScript event listeners and dynamic DOM manipulation.

## 📋 Table of Contents

- [Topics Covered](#topics-covered)
- [Project Structure](#project-structure)
- [How to Run](#how-to-run)

## 📚 Topics Covered

- **Event Handling:** Implementing `onclick` and `addEventListener` (`click`, `input`, `submit`, `keydown`).
- **Form & Input Validation:** Preventing default form submission (`event.preventDefault()`) and providing real-time input feedback.
- **DOM Content Manipulation:** Updating elements dynamically using `textContent`, `innerHTML`, inline `style`, and `classList.toggle()`.
- **Dynamic Element Creation:** Creating, appending, and removing HTML elements using `document.createElement()`, `appendChild()`, and `remove()`.
- **Mini Project:** Responsive mobile navigation toggle (Hamburger Menu) with outside-click detection.

## 🚀 How to Run

1. Clone or download this repository:
   ```bash
   git clone https://github.com/dwizrakhman/javascript-dom-manipulation.git
   ```
2. Open the project folder in **Visual Studio Code**.
3. Right-click any `.html` file and select **Open with Live Server** (or open it directly in your browser).
4. Press `F12` to open **Browser DevTools** if you want to inspect elements or console logs.
